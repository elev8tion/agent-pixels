# Sync your .pi models into Agent Pixel

Run this to instantly make every model you've configured in Pi available inside the extension:

```bash
npm run sync-pi
# or
node scripts/sync-pi-models.js
```

Then in the extension:

1. Open side panel
2. Click the gear icon
3. Click **"Sync from local Pi"**
4. Choose any of your models (including reasoning effort)

The server runs for 90 seconds.

Chrome extension included

Side panel, background worker, content bridge.

Load Agent-Pixel/extension as an unpacked Chrome extension. It captures visible tabs, extracts a DOM map, stores provider preferences, and sends page context to the local Agent-Pixel server.

  1. Run npm run dev from Agent-Pixel.
  2. Open chrome://extensions, enable Developer Mode.
  3. Choose “Load unpacked” and select Agent-Pixel/extension.
  4. Open the side panel, capture the current tab, then ask Agent-Pixel.
